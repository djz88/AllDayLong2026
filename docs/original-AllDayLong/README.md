# Original AllDayLong references

This directory contains the historical reference images from the original AllDayLong release and its timed XML configuration.

The reference images are not AI-generated. Their author is unknown.

These files serve as input references for the process described in `../PROMPT-INSTRUCTIONS.md`. The installation scripts for the current 4K version do not use them.

- `01.jpg` through `08.jpg`: JPEG, 1280 × 800, 16:10 aspect ratio.
- `AllDayLong.xml`: original timing and image order.

Keep the files in this directory unchanged. New output belongs in the root-level `images/` directory, not here.

The authorship and license status of the original images have not been reliably confirmed. Historical links are listed in `../SOURCES.md`, and a more detailed license notice appears in the “Origin, authorship, and license” section of `../../README.md`.
